## About

Hi, I'm Adon, a Java developer with around five years of experience. Java is what I know best and what I enjoy most, and I'm always working to get better at it, from writing cleaner code to designing stronger, more reliable systems. I'm also growing my backend web development skills so I can build complete applications, from the database all the way to the browser.

I like building things from scratch and seeing them through to the finish, but I'm just as comfortable jumping into an existing project and getting up to speed fast. When a task gets tricky, I dig in until it's solved. People can count on me to deliver, and I keep clients and teammates in the loop and look after them even after the work is done.

As co-owner of **Avalon Development**, a gamemode and plugin development studio, I handle client commissions, build core plugins, and provide support. I've also spent four years working alongside the **JackpotMC** team.
